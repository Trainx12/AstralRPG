# Nave del Vacio (nave.py). Con AstralNave y WorldEdit; subir antes .local/nave/spaceship.schem a plugins/WorldEdit/schematics/spaceship.schem
# 1) Crear los mundos (vacios, el generador es el de AstralOceano):
mv create nave normal --generator AstralOceano:vacio --no-structures
mv create nave_2 normal --generator AstralOceano:vacio --no-structures
mv create nave_3 normal --generator AstralOceano:vacio --no-structures
# 2) Pegar la nave en cada uno (consola). La schematic carga en segundo plano: esperar el mensaje
